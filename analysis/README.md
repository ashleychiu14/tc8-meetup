## 4. 三個最需要留意的結構性事實

### (a) 報酬高度集中於單一 81 天窗口
- 前 437 天（佔全期 75% 時間）：**+7.47%**
- 2026-03-30 之後 142 天（佔 25% 時間）：**+29.96%**

全期 CAGR 23% 幾乎完全由 2026 年 4–6 月一段行情產生。
**這個 CAGR 不可外推**，也不能當作「策略年化報酬」引用。

### (b) 83 天的資料盲區（2025-08-12 ~ 2025-11-03）
只知道端點淨含 +6.35%，中間路徑完全未知。這代表：
- 最大回撤 -21.96% 只是**下界**，盲區內可能有更深回撤
- 2025 全年任何統計（波動、月勝率、Sharpe）都不可信
- 若要把這段資料當 benchmark 對照，這 83 天必須排除或補齊

### (c) 波動特徵偏高
年化 ~31%，約為大盤的 1.5–2 倍。旁證：
- 2025-04-07 → 04-09 兩天 **+13.26%**（同期 S&P 500 約 +7~8%）
- 2026-07-02 → 07-03 單日 **-4.96%**
- 2025-02-21 → 04-07 跌 -21.96%（同期 S&P 500 收盤價約 -19%）

指向**高 beta、集中持股或帶槓桿**的組合。這點必須用持倉資料確認，
不能只從淨值推斷。

## 5. 關於「週期」的警告

兩年確實同形：2 月中下旬做高 → 45~46 天後見底 → 4–6 月強彈。

**但 n=2。** 兩次觀測不足以構成週期，把它當交易依據是典型的過擬合。
2025 的 2–4 月下跌有明確外生事件對應（關稅），2026 的成因未經驗證，
兩者形狀相似很可能只是巧合。

自由度檢查：136 個觀測點、6 次獨立回撤循環、1 個完整年度。
以「每個可調參數需 10–30 個獨立事件」的經驗法則，
**這份資料能支撐的自由參數數量是 0。**

## 6. 這份資料能用來做什麼 / 不能做什麼

**能做（僅需淨值）**
1. 風險預算校準 — 用實際 -22% 回撤與 61% 水下時間，檢驗自己的部位大小與心理承受度是否匹配
2. Out-of-sample 檢核 — 若已有在別處開發的策略，可拿這段當**純驗證集**（不調參）
3. 同日 benchmark 對照 — 抓 SPY/QQQ 在這 136 個相同日期的收盤價，算相對強弱與 beta
4. 回撤修復期統計 — 修復期 15~78 天，可用來設定「多久沒新高就檢討」的門檻

**不能做**
1. 回測任何策略 — 沒有交易紀錄、持倉、進出場時點，無法重現決策
2. 績效歸因 — 分不出 alpha / beta / 選股 / 擇時 / 幣別
3. 算可信的 Sharpe — 取樣間隔 1~83 天不等，波動估計有偏
4. 擬合停損、加減碼、輪動等任何參數 — 自由度為 0

## 7. 要補的資料（依重要性）

1. **日頻 NAV 全序列** — 券商都可匯出（IBKR: Flex Query / Activity Statement 的 NAV time series；Schwab/Fidelity: Portfolio History export）。補完後盲區消失，最大回撤與波動才是真的
2. **交易紀錄（成交日、標的、股數、價格）** — 沒有這個就沒有回測，只有績效紀錄
3. **每日持倉快照** — 才能算 beta、產業曝險、集中度
4. **現金 / 保證金餘額** — 確認 2026 年 4–6 月的加速是行情還是加槓桿
5. **股息與稅** — 分離價格報酬與總報酬
